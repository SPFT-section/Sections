# 📚 SECTiON

เว็บแอปสำหรับเขียนและอ่านนิยายแบบ Local-First ตกแต่งด้วยสไตล์ Glassmorphism

## 🚀 คุณสมบัติ
- ✅ เขียนและอ่านนิยายแบบออฟไลน์
- ✅ เก็บข้อมูลในเครื่อง (Local Storage / IndexedDB)
- ✅ ปรับแต่งการอ่านได้ตามใจ
- ✅ รองรับ Light / Dark Mode
- ✅ ใช้งานได้ทุกอุปกรณ์
- ✅ ระบบเข้าสู่ระบบ / ออกจากระบบ พร้อมกู้คืนรหัสผ่าน
- ✅ ใช้งานแบบ Guest ได้โดยไม่ต้องสมัครสมาชิก
- ✅ ป้องกันการคัดลอกเนื้อหานิยายขณะอ่าน

## 🔐 บัญชีผู้ใช้

แอปนี้เป็นแบบ Local-First ทุกอย่างเก็บอยู่ในเบราว์เซอร์ของคุณเท่านั้น ระบบบัญชีจึงเป็นชั้นข้อมูลประจำตัว/ความสะดวก ไม่ใช่การป้องกันความปลอดภัยระดับเซิร์ฟเวอร์

- **สมัครสมาชิก**: ตั้งชื่อผู้ใช้ รหัสผ่าน (อย่างน้อย 6 ตัวอักษร) และคำถาม–คำตอบกู้คืนรหัสผ่าน รหัสผ่านจะถูกแฮชด้วย PBKDF2 (Web Crypto API) ไม่มีการเก็บรหัสผ่านแบบข้อความล้วน
- **เข้าสู่ระบบ / ออกจากระบบ**: คลิกปุ่มที่มุมขวาบนของ Header
- **ลืมรหัสผ่าน?**: กดลิงก์ "ลืมรหัสผ่าน" กรอกชื่อผู้ใช้ ตอบคำถามกู้คืนที่ตั้งไว้ตอนสมัคร แล้วตั้งรหัสผ่านใหม่ได้ทันที (ไม่ต้องใช้อีเมล เพราะแอปไม่มีเซิร์ฟเวอร์)
- **Guest**: ไม่ต้องเข้าสู่ระบบก็ใช้งานแอปได้ครบทุกฟีเจอร์ตามปกติ — นี่คือโหมดเริ่มต้น

## 📋 การป้องกันการคัดลอกเนื้อหา

หน้าอ่านนิยายปิดกั้นการเลือกข้อความ คลิกขวา ลาก และคีย์ลัดคัดลอก/พิมพ์ทั่วไป เพื่อความสวยงามของหน้าอ่านและกันการคัดลอกแบบทั่วไป **หมายเหตุ:** นี่เป็นการป้องกันระดับหน้าเว็บ (deterrent) ไม่ใช่ DRM ที่สมบูรณ์แบบ ผู้ใช้ที่เปิด dev tools ของเบราว์เซอร์ยังสามารถเข้าถึงเนื้อหาได้
